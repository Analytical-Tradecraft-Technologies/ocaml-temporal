# Code of conduct

> **Status: draft pending maintainer adoption (#1140).** This file proposes
> adopting the Contributor Covenant. It takes effect only when the maintainer
> approves it and fills in the enforcement contact below.

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The linked text is the authoritative version; it is
published by the Contributor Covenant project under the
[Creative Commons Attribution 4.0 license](https://creativecommons.org/licenses/by/4.0/).

## In short

We want this to be a welcoming and harassment-free project for everyone,
whatever their background, identity or level of experience. In issues, pull
requests, reviews and every other project space:

- be respectful and assume good intent, and disagree about technical choices
  on their merits;
- give and accept constructive feedback, and own your mistakes;
- do not harass, insult or demean anyone, and do not publish anyone's private
  information without their explicit permission.

The full standards, the enforcement responsibilities and the enforcement
guidelines (correction, warning, temporary ban, permanent ban) are those of
the Contributor Covenant 2.1 linked above.

## Scope

This code applies in all project spaces, such as this repository's issues,
pull requests, discussions and reviews, and when someone officially
represents the project elsewhere.

## Reporting

Report unacceptable behavior privately to the project maintainer at
**[enforcement contact to be provided by the maintainer]**. Reports are
reviewed promptly and handled confidentially. Do not use public issues to
report conduct problems or security vulnerabilities; see
[CONTRIBUTING.md](CONTRIBUTING.md#reporting-a-security-problem) for security
reports.
