# Per-compiler-series exceptions to temporal-sdk.opam.locked.
#
# Format: <OCaml MAJOR.MINOR> <locked package> <exact version>
#
# temporal-sdk.opam.locked is solved for OCaml 5.2.1. scripts/opam-locked-deps.sh
# installs every non-compiler package at its locked version on every supported
# compiler series, except where a line below replaces that version for one
# series. An entry is permitted only when OPAM metadata makes the locked
# version uninstallable for that compiler, only for a package already in the
# lock, and only after `make license-check` has audited the replacement (the
# licence audit reads this file as well as the lock). Prefer a build-only tool;
# a replaced runtime library needs an explicit review note here.
